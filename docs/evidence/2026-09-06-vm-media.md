their observations were synthetic and do not qualify a renderer. Negative
cases reject other assignments, epochs, revisions, original photos or converted
bytes, missing readiness, invalidated commits, mismatched group/binding,
out-of-interval presentation, and fallback observations. Review caught an
initial missing original-photo binding; the corrected gate requires the
worker's original SHA-256 to match the uploaded portrait, then separately
preserves the converted JPEG SHA-256 across restart/rollback.

The integrated build/boot/media focused run passed **149 tests** with one
dependency warning. The full PostgreSQL-backed suite then passed **1,001 tests /
15 explicit platform or opt-in skips / four warnings** in 110.76s, log
`/private/tmp/photo-wall-native-media-final-regression.log`.

Final evidence review found a false-negative risk: the coordinator renews valid
commit timestamps on later ticks, so its latest row can postdate an already
delivered observation. The correction retains bounded real grant snapshots
during the host's polling window, preserving the strict commit-before-drawing
test instead of inventing historical timestamps. It still requires matching
identity/authority/assignment/group and a valid current commit. **49 focused
tests passed** afterward, including real PostgreSQL grant capture, renewal and
invalidation, with one dependency warning. Hosted image evidence remains pending.

## Independent cache-gate correction

Integrated strong review found a P2 qualification defect: allowing media
re-download after reboot meant a wiped cache could be repopulated before the
final disk check. The unmodified gate passed a simulated platform that lost its
cache twice and downloaded three times. This did not establish a production
Cache defect; no passing native-image result had depended on it.

After the initial drawing and stopped-disk proof, the corrected harness creates
a persistent media-delivery denial in a separate owned fixture-control volume.
The gateway mounts it read-only and returns a fixed 503 response for media
requests, while control/authority remains available. The worker mounts it as
the checked test writer; its production media garbage collector cannot remove
this separate control state. Exact denial is verified before and after both
later drawings. There is no requirement for zero GET attempts: a cache hit may
still coincide with an unsuccessful network attempt.

Independent review closed P2 after **158 focused tests passed / one database
skip / one dependency warning**. Removing the denial in an in-memory mutation
made both cache-loss regression tests fail; the preserved-cache case passes.
No other P1/P2 was found in the reviewed readiness/commitment/observation/cache
and epoch paths. Earlier selected PostgreSQL review checks passed **59 tests**.
Full-image native rendering, automatic rollback and physical acceptance remain
unqualified.

The root's final fixture/host/gateway run passed **115 tests / one dependency
warning in 3.69s**, including separate control-volume ownership and strict
boolean opt-in. Workflow, Ruff and documentation checks passed. Public fixed
media setup phases now preserve where a future setup failure occurred without
exporting private command output.
