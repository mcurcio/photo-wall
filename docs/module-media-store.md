# Media storage and delivery leases

Status: implementation contract, 2026-09-05; fault evidence is recorded after execution. This module implements [decision 0004](decisions/0004-media-publication-and-worker-recovery.md) under the source/job repository and [media preparation](module-media-preparation.md) boundaries. It owns local bytes, publication recovery, collection, and authorized read descriptors; it never selects, downloads, converts, or grants execution.

## API and state ownership

`MediaStore(repository: MediaRepository, root: Path)` uses the repository's database, Clock, limits, and shared `MEDIA_LOCK`. `worker_lock()` is a lifetime context that refuses a second writer, creates private store directories, and reconciles before yielding. All filesystem mutation requires that context. The gateway creates its own store instance and uses only `open_read(token, digest)`.

`staging(lease) -> StagingPaths(directory, original, variant)` validates a current reserved job before creating its private attempt directory. Paths contain only central job/attempt identifiers and fixed leaf names. The adapter writes `original`; the preparer writes `variant`. `publish(lease, PreparedMedia) -> Variant` verifies the original, derivative, attempt, and recipe, journals publication, durably renames, cleans staging, and finalizes readiness. `fail(lease, code, retry=False)` records a bounded code and whether the domain job remains retryable before cleaning; Procrastinate owns retry timing. Cleanup failure retains accounting. `recover() -> RecoveryReport` reconciles while the exclusive writer is held. `collect(target_bytes=None) -> GCReport` deletes only unreferenced blobs under the same quota lock used to create references. `set_quota(max_bytes)` changes capacity without invalidating pins.

Publication stores exact prepared result metadata in `media_jobs.result`, excluding `path` and adding `asset_id` and `original_sha1`; `cleanup_state` preserves the intended final state across unlink failure. Before rename, a `publishing` blob takes over precisely its byte count from the job reservation. The reservation retains the original and other possible staging bytes until those files are removed. Canonical files are `blobs/<sha256>`; staging is `staging/<job_id>/<attempt_token>/{original,variant}`. A duplicate ready digest must match the entire Variant and verified canonical bytes; it does not acquire a second blob charge. No ready job/catalog attachment appears until durable publication and cleanup finish.

Restart recovers completed publishing files from either canonical or staged locations, validates exact journal identity, and then finishes. Missing/corrupt publication cannot become ready. Interrupted ordinary attempts become retry only after cleanup. Untracked files that cannot be removed are recorded in `media_orphans` and counted as pressure; an error must not turn actual disk use into apparently free quota. Unknown files are never interpreted as a ready Variant. Corrupt ready blobs retain logical assignment locks and references; new reads/offers fail. `deleting` rows remain accounted until physical removal succeeds.

Corruption that enlarges a file raises its accounted blob size to the larger measured byte count while preserving its original immutable Variant metadata. Source catalogs are refreshed after ready/corrupt/deleting transitions. `collect()` normally retains unreferenced ready cache while total use is within quota. To make room for a new reservation, the worker supplies `target_bytes=max(0, quota-required_reservation)` before retrying a pressure-blocked claim. Recovery is only called at startup or after all acquisition/conversion activity has stopped and been reaped; the lifetime writer lock does not make it safe to delete staging beneath the same worker's active subprocess.

## Read authorization and lifetime

`open_read(token, digest) -> ReadLease` authenticates the current Registry epoch and rechecks current Frame generation in the same transaction that creates a transfer reference. Authorization requires an unexpired exact offer or secured reference, the corresponding exact Layer Variant, and a still-authorized binding. A guessed digest, expired offer, stale epoch, replaced Frame binding, corrupt blob, symlink, or nonregular path yields a coded refusal. The read opens only the canonical local file and verifies size/hash before returning bytes. There are no redirects or upstream requests.

`ReadLease` exposes `variant`, `read(size=65536)`, `close()`, and context-manager cleanup. Reads are bounded to 64 KiB and exact remaining file size. Its whole lifetime is bounded to 120 seconds by real and injected monotonic time, with a timer that closes an idle descriptor; the gateway must also wrap the complete streaming response in its own 120-second timeout. A 150-second transfer reference protects the file through the deadline plus cleanup margin. Completion, disconnect, errors, and timeout close the descriptor before releasing the reference. If reference deletion fails after closing, expiry preserves conservative pressure. Every new request authenticates independently.

## Acceptance evidence

Tests use generated local bytes and a real PostgreSQL schema per test. They must cover exclusive writer refusal, reservation-before-directory creation, exact original/recipe/Variant verification, deduplicated accounting, journal crash boundaries, stale attempt refusal, failed unlink pressure, startup orphan/deleting/corruption recovery, quota reductions preserving pins, exact offer/secured authorization, retirement/rebind refusal, and transfer cleanup/expiry. Such checks establish local POSIX/database behavior on the executing host, not arbitrary network-filesystem semantics or production HTTP streaming integration.

Executed 2026-09-05: `.venv/bin/python scripts/test_local.py -q tests/test_media_store.py` passed **37 tests** against the task's PostgreSQL instance using isolated temporary schemas and real local files. Injected publication faults cover before rename, after rename, and after staging removal; recovery refuses altered recipe/original/Variant journal metadata. A separate real child process held the writer lock and was killed to verify OS release. An idle read's actual descriptor closed under its shortened test deadline and released its transfer reference. Ruff passed for both owned Python files, the documentation checker passed 34 Markdown files, and the owned diff whitespace check passed. The only warning was an existing Starlette/AnyIO deprecation.

The tests do not decode their generated byte strings: preparation has its separate native-media evidence. This leaf does not claim a completed HTTP response path, a deployed Linux worker filesystem, real Immich delivery, or physical Player presentation. Upward review and those integration checks remain with the orchestrator.
